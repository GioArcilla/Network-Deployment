# Network-Deployment
The purpose of this repository is to highlight key network essentials for devices.


## Features
- Initial setup
- VLANs
- L2/L3 Etherchannels
- HSRP
- IP Addressing
- RSTP
- Static Dynamic Routing
- DHCP
- DNS
- NTP
- SNMP
- Syslog
- FTP
- SSH
- NAT
- Security; ACLs and L2 sec features
- RDP
