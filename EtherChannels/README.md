# Layer 2 Etherchannel

## Key Features
- Operates in the data layer of the OSI model
- Traffic based on MAC addressing
- Traffic Type: Bridged
- Configuration: switchport 




# Layer 3 Etherchannel

## Key Features
- Operates in the network layer of the OSI model
- Traffic based on IP addressing
- Traffic Type: Routed
- Configuration: no switchport
